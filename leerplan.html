Persoonlijke ontwikkeling

Individueel Leerplan

Mijn leerdoelen, ontwikkeling en reflectie binnen HBO-ICT.

Waar gaat deze opdracht over?

In mijn individueel leerplan reflecteer ik op mijn ontwikkeling binnen de opleiding. Hierbij kijk ik naar mijn technische vaardigheden, persoonlijke groei en professionele houding.

Mijn leerdoelen

  • Manier van plannen verbeteren
  • Meer onderzoek doen van te voren.
  • Alles gelijk documenteren nadat ik de code heb geschreven, niet een dag wachten.

Wat laat ik hiermee zien?

Met deze opdracht laat ik zien dat ik bewust bezig ben met mijn ontwikkeling. Ik kijk niet alleen naar het eindresultaat, maar ook naar wat ik leer tijdens het proces.

De opdracht

Rol: creative technologist

Binnen het project the punishing home vervul ik de rol creative technologist. Dit betekent dat ik mij in meerdere richtingen verdiep. Bijvoorbeeld dat ik mij richt op de technische werking, hoe technologie wordt toegepast op een creative manier en hoe de beleving van dit project samenkomt voor uiteindelijk de gebruiker. Het doel van het project is dat slimme technologie ook een donkere kant kan hebben. In plaats van alleen gemak en comfort bieden, onderzoeken ik hoe technologie ook op een confronterende manier kan worden ingezet om gedrag te beïnvloeden.

Analyseren:

Binnen het project heb ik onderzocht hoe de pico w functioneert in combinatie met een smart lamp, buzzer, led en wifi. Ik heb hierbij gekeken naar hoe deze onderdelen samenwerken en hoe data verzonden kan worden. Daarnaast heb ik onderzocht hoe dit systeem kan worden gekoppeld aan AI, waarbij de AI een signaal kan geven wanneer de gebruiker zijn focus verliest. Op dat moment wordt er een straf uitgevoerd, zoals een hard piep geluid via een buzzer of frequentie via de pc. Ook heb ik gekeken naar een mogelijke andere oplossing als de wifi van eduroam niet zou gaan werken bijvoorbeeld met een hotspot of een heel ander plan erbij maken als plan B, zodat het toch gaat werken.

Adviseren:

Vanuit mijn rol heb ik een voorstel gedaan om het project te verbeteren. Het concept zal hetzelfde blijven, maar om het wat interessanter te maken voor de gebruiker leek het mij handig om een score eraan vast te plakken via een dashboard. Zo wordt het project meer aantrekkelijk om te proberen om je focus te meten.

Ontwerpen:

Ik heb meegedacht over het ontwerp van het systeem, waarbij ik heb gekeken naar het gehele plan van het begin tot het eind bij de floor expo. Ik heb nagedacht hoe het systeem zou moeten werken met de input van de gebruiker. Daarnaast heb ik geholpen met de code schrijven voor mijn gedeelte van het project om ervoor te zorgen dat het systeem een geheel wordt en dat de straf uitgevoerd kan worden.

Wat wil ik verbeteren?

Mijn plan is momenteel afhankelijk van wifi, wat een probleem vormt omdat de schoolwifi niet wordt ondersteund door de pico w. Daarom wil ik een plan B ontwikkelen, zoals helemaal de pico niet gebruiken en een irritant hard geluid creëren via code en te laten afspelen vanuit mijn laptop en koptelefoon. Dit is zodat mijn onderdeel van project betrouwbaar blijft werken
